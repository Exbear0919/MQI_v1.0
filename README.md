# 🏥 医疗质量指标查询系统

> 完整的医疗质量管理与控制指标数据库，支持离线查阅、关键词搜索、分类浏览。

## 📋 指标概览

| 统计项 | 数量 |
|--------|------|
| 指标总数 | 833 条 |
| 分类数量 | 48 个专科类别 |
| 含计算公式 | 覆盖全部计算类指标 |
| 含子指标 | 支持多层级展开 |

## 🎯 功能特性

- **🔍 全文搜索** — 输入任意关键词（指标名称、定义、公式）实时过滤
- **📂 分类浏览** — 按 48 个临床专科分类查看指标
- **📐 数学公式展示** — 以分子/分母分数形式直观呈现计算公式
- **📖 完整字段** — 定义、计算公式、指标意义、说明等全部字段
- **🌙 深色模式** — 自动跟随系统主题
- **📱 响应式布局** — 适配桌面、平板、手机
- **⚡ 完全离线** — 纯静态 HTML，无服务器依赖，可本地打开
